# WhoChanged – Admin Activity & Audit Log

[![WordPress Plugin](https://img.shields.io/wordpress/plugin/v/whochanged?label=WordPress.org)](https://wordpress.org/plugins/whochanged/)
[![License: GPLv2+](https://img.shields.io/badge/license-GPLv2%2B-blue.svg)](https://www.gnu.org/licenses/gpl-2.0.html)

Know exactly **who changed what** in your WordPress admin — options, Customizer, plugins, users, menus, content and more — with clear before/after diffs.

**Website:** [https://douple.net/whochanged/](https://douple.net/whochanged/)  
**Docs:** [https://douple.net/whochanged/docs.html](https://douple.net/whochanged/docs.html)  
**Demo:** [https://douple.net/whochanged/demo.html](https://douple.net/whochanged/demo.html)  
**WordPress.org:** [https://wordpress.org/plugins/whochanged/](https://wordpress.org/plugins/whochanged/)  
**Support:** support@douple.net

## Features

- Before/after diffs for admin option changes
- Customizer, plugins, users, menus and content events
- WooCommerce order deletions (when WooCommerce is active)
- Filterable activity log (user, event type, date range)
- Statistics dashboard and admin bar quick menu
- CSV export
- 30-day activity history on every Free install
- Log data stays in your own WordPress database

## Requirements

- WordPress 6.0+
- PHP 7.4+
- WooCommerce optional (only for WooCommerce-specific events)

## Installation

1. Download from [WordPress.org](https://wordpress.org/plugins/whochanged/) or clone this repository into `wp-content/plugins/whochanged`
2. Activate **WhoChanged – Admin Activity & Audit Log** from **Plugins**
3. Open **WhoChanged** in the admin sidebar to view the activity log

## Development

Human-readable plugin-owned JavaScript and CSS ship under `assets/js/` and `assets/css/`. Third-party libraries under `assets/js/vendor/` and `assets/css/vendor/` are upstream builds (Chart.js, Flatpickr).

No build tools are required to review or modify the plugin-owned admin scripts and styles.
